# Specifications (`docs/specs/`)

This directory stores authoritative, RFC 2119-compliant engineering specifications authored during **Phase 3 (`/flow-spec`)** of the `agy-flow` engineering lifecycle.

---

## Conventions & Standards

- **Naming Convention**: `YYYY-MM-DD-[feature-name]-spec.md` (e.g. `2026-09-01-jwt-auth-spec.md`)
- **Canonical Template**: [`templates/spec.md.template`](../../templates/spec.md.template)
- **Normative Language**: All requirements use uppercase RFC 2119 keywords (`MUST`, `MUST NOT`, `REQUIRED`).
- **Traceability**: Each requirement defines a verifiable Acceptance Criterion ID (`AC-XX`).
- **Privacy Notice**: Generated project-specific specifications in this directory are gitignored by default.
