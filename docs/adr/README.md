# Architecture Decision Records (`docs/adr/`)

This directory maintains the master index and formal records of significant architectural, technical, and infrastructure decisions authored via **`/flow-adr`**.

---

## Conventions & Standards

- **Naming Convention**: `NNNN-[short-title-with-dashes].md` (e.g. `0001-use-postgresql.md`)
- **Supported Formats**: Standard MADR (Markdown Architectural Decision Records), Compact Y-Statement, and RFC Proposal.
- **Lifecycle Tracking**: Decisions track state (`Proposed`, `Accepted`, `Rejected`, `Deprecated`, `Superseded by ADR-NNNN`).
- **Privacy Notice**: Generated project-specific ADRs in this directory are gitignored by default.
